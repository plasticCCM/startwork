STARTWORK — локальное приложение

ЗАПУСК
1. Откройте PowerShell в этой папке.
2. Выполните: powershell -ExecutionPolicy Bypass -File .\start.ps1
3. Откройте http://127.0.0.1:8000
Первичная установка на другом компьютере: тот же скрипт создаст .venv;
если окружение есть, но зависимости ещё не установлены: .\start.ps1 -Install
Требуется Python 3.12+; сервер слушает только локальный интерфейс.

ИИ ЧЕРЕЗ CHATANYWHERE
Файл .env уже подготовлен. Вставьте ключ ChatAnywhere после DEEPSEEK_API_KEY= и
сохраните файл. Настройки DeepSeek перечитываются без перезапуска. Ключ остаётся на сервере и не отправляется браузеру.
DEEPSEEK_URL=https://api.chatanywhere.org/v1/chat/completions
DEEPSEEK_MODEL=deepseek-v4.1-flash
DEEPSEEK_URL — полный endpoint; путь /chat/completions не дописывается.
Официальная информация провайдера: https://github.com/chatanywhere/GPT_API_free
При отсутствии DEEPSEEK_URL сохраняется совместимость с DEEPSEEK_BASE_URL;
если не задано ни одно поле, используется адрес ChatAnywhere выше.
Без ключа можно создать, отредактировать и опубликовать курс вручную.
Текст документов при генерации передаётся ChatAnywhere для обработки выбранной моделью; исходные файлы не сохраняются.
Задания генерируются в JSON, проверяются структурно. Дословность цитат сверяется
с исходником. Все части исходного текста обрабатываются, но полнота покрытия
тем и корректность модели всё равно требуют проверки наставником.

БАЗА ДАННЫХ
По умолчанию SQLite: data/startwork.db. Регистрации, права, курсы и прогресс
сохраняются между запусками. Для командной работы предусмотрен PostgreSQL:
1. Установите Docker Desktop и выполните docker compose up -d.
2. В .env укажите DATABASE_URL из .env.example.
3. Перезапустите сервер: таблицы создадутся автоматически.
Переключение базы создаёт отдельный набор данных; переноса SQLite автоматически нет.
Пароль compose предназначен только для локальной разработки; смените его для хостинга.
Для изменения схемы после развития проекта нужны отдельные миграции.

КАК ПРОВЕРИТЬ
— Зарегистрируйте наставника: логин, пароль хотя бы с одной цифрой. Почта необязательна.
— Создайте курс, загрузите PDF / DOCX / TXT / MD или вставьте текст.
— Подготовьте курс с ИИ или добавьте темы и задания вручную.
— В редакторе проверьте материал и правильные ответы, сохраните и опубликуйте.
— Второй наставник регистрируется отдельно. Пригласите его по логину.
  До принятия приглашения в разделе «Приглашения» курс ему не доступен.
— Обучающийся регистрируется с соответствующей ролью. Назначьте ему курс по логину.
— Обучающийся читает тему и выполняет задания. Для следующей темы нужен результат 100%.
— Результаты видны создателю и принявшим приглашение наставникам курса.

ПРАВА И ВЕРСИИ
Регистрация открытая: пользователь выбирает роль; в первой версии нет организаций
и общего администратора. Чужие курсы не видны даже другим наставникам.
Приглашённые наставники могут редактировать, публиковать, назначать обучение,
просматривать результаты и приглашать коллег. Отозвать доступ может создатель.
Правки черновика не меняют публикацию. Каждое назначение хранит снимок курса:
его прогресс и ответы сохраняются при последующих изменениях. Автоматического
переназначения или сброса прогресса нет.

ФОРМАТЫ И ОГРАНИЧЕНИЯ
До 6 файлов, вместе до 10 МБ, до 120 000 символов на курс, PDF до 200 страниц.
Старый .doc нужно сохранить как .docx. Сканированные страницы требуют OCR
вне приложения; если текст со страницы не извлечён, PDF не принимается целиком.
В Word читаются основные абзацы и таблицы; изображения, сноски, комментарии,
колонтитулы и текстовые блоки могут потребовать ручного копирования в исходник.
Нет свободных ответов: один/несколько вариантов, сопоставление, последовательность.
Автоматический запуск без ключа не имитируется: интерфейс покажет причину.
Задачи генерации выполняются в процессе приложения. После перезапуска
незавершённые задачи помечаются ошибкой и требуют повторного запуска.
Не запускайте несколько серверных процессов для этой локальной версии.

ПРОВЕРКИ
.venv\Scripts\python.exe -m pytest -q
Тесты используют отдельную временную базу. Реальные ключи и документы не нужны.

ПЕРЕД ПУБЛИЧНЫМ РАЗМЕЩЕНИЕМ
Эта версия запущена локально. Для внешнего сервера настройте HTTPS,
COOKIE_SECURE=true, PostgreSQL, резервное копирование, общую очередь задач
и распределённое ограничение попыток входа. Восстановления пароля и подтверждения
почты в упрощённой регистрации пока нет.

ПОДГОТОВКА КУРСА
Черновик можно сохранить без тем или заданий; публикация требует полного курса.
В блоке подготовки видны этапы, время с начала запуска и число обработанных частей.
Провайдер не сообщает точный процент внутри одного запроса: пока ждём ответ,
показывается ожидание, а не искусственно растущая шкала. Ошибка баланса или
провайдера появляется в этом же блоке. Все исходные материалы сохраняются.

ПРОФИЛЬ И НАВИГАЦИЯ
Логотип и личное пространство открывают обзор. Аватар справа сверху, имя
слева снизу и пункт «Настройки профиля» открывают профиль. Можно изменить
имя и необязательную почту, а также пароль с проверкой текущего. После смены
пароля остальные сеансы завершаются; текущий сохраняется. Логин и роль
не меняются. Favicon доступен в ICO и SVG, шрифты хранятся локально.

Подключение ChatAnywhere использует стандартный JSON chat/completions без
специфичных параметров thinking/reasoning_effort. Нужен ключ ChatAnywhere.
FLASK_SECRET_KEY не используется: приложение работает на FastAPI.
При переходе со старого прямого DeepSeek-конфига прежний .env сохранён
в data/config-backups/direct-deepseek.env (если такой конфиг существовал).
Этот файл не входит в архив исходников.

МОДЕЛЬ ПО УМОЛЧАНИЮ
Выбрана deepseek-v4.1-flash через ChatAnywhere как начальный вариант для прототипа:
короткие фрагменты инструкций, JSON-курс, вопросы и объяснения. Качество
на реальных материалах и скорость ещё предстоит измерить с действующим ключом.
Модель можно сменить через DEEPSEEK_MODEL; имя переменной оставлено для
совместимости. Автоматического переключения на более дорогие модели нет.
Источники: https://github.com/chatanywhere/GPT_API_free
https://docs.chatanywhere.tech/doc-2694962

НАЗНАЧЕНИЕ ОБУЧЕНИЯ
В опубликованном курсе нажмите «Назначить обучение». Выберите зарегистрированных
обучающихся из списка или найдите по имени / логину. Можно выбрать до 50 человек
за раз; выбор сохраняется при смене поискового запроса. Уже назначенные курсы
отмечены и повторно не назначаются, существующий прогресс не сбрасывается.
Список показывает только имена и логины, без почты. Поиск и назначение доступны
только наставникам, у которых есть доступ к этому курсу.

ПРИГЛАШЕНИЕ НАСТАВНИКОВ
Во вкладке «Наставники» нажмите «Пригласить». Доступен список зарегистрированных
наставников, поиск по имени или логину и выбор нескольких человек. Создатель,
участники и ожидающие приглашения отмечены в списке. Отклонившего запрос
можно пригласить снова. Доступ открывается только после принятия приглашения.

УДАЛЕНИЕ КУРСА
Только создатель видит кнопку «Удалить курс». Для подтверждения нужно ввести
точное название. Удаление необратимо: удаляются материалы, приглашения,
назначения и результаты этого курса. Аккаунты пользователей сохраняются.
Пока готовится курс с ИИ, удаление заблокировано до завершения обработки.
